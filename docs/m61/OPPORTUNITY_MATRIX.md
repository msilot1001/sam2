## 3. 우선순위와 GPU 배분

1. **D (적합 데이터 20분)와 A (10분):** 비용이 낮고 결과가 명확하다. 먼저 돌린다.
2. **B (약 2시간):** 개선 대상 범위가 가장 넓다(작은 대상만이 아니라 전체 오차). 하지만 선행연구 위험이 가장 크다. 양성 대조를 관문으로 둔다.
3. **C:** CPU 진단만 한다(agent). 독립 영상 기준을 충족하면 그때 GPU를 배정한다.
4. 남는 시간에는 가장 강한 후보의 ablation을 하고, 사전 기준을 충족할 때만 C 확인을 한다.

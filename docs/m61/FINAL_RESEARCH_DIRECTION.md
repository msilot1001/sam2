> - 이 실패는 **교차 view 존재 신뢰도**(전역 추적기도 대상이 있다고 볼 때만 국소 출력 채택)로 제거된다.
>   - 다만 이 규칙의 측정된 이득은 **그 객체 하나에서 나온다.** 그 객체를 빼면 A2x 대비 −0.0015 [−0.005, +0.001]이다.
> - **추천:**
>   - 연구 방향: 전역–국소 SAM 2와 그 신뢰도
>   - M7 주 비교 arm: **SGGL(A2x)과 SGGL-V(+ 존재 거부권)를 공동 1차 arm으로 둔다**
> - 신뢰도는 **PROVISIONAL**이다. 사전 관문 +0.03 미달, 거부권은 사후에 설계, 표본이 작다.

**Research title**
- **KO:** 극소 대상 비디오 객체 분할을 위한 전역–국소 SAM 2 추론: 자기 신호 gate와 교차 view 존재 신뢰도
- **EN:** Global–Local SAM 2 Inference for Tiny-Target Video Object Segmentation: Self-Gating and Cross-View Presence Reliability

**Research question**
> 전체 frame SAM 2 상태와 고정 객체 상대 배율의 crop SAM 2 상태를 독립적으로 돌린다. 국소 출력은 다음 두 조건을 모두 만족할 때만 채택한다.
> - 국소 상태 자신의 신호: object score > 0, 내부 crop 경계 미접촉
> - 전역 상태의 존재 판단: 전역 object score > 0
>
> 이 학습 없는 추론이 다음 세 조건을 만족하는가? 거부권 없는 SGGL과 거부권 있는 SGGL-V 중 어느 쪽이 나은지도 함께 묻는다.
> 1. 극소 대상(prompt 면적 < 0.1%)의 mask J&F를 P5보다 ≥ +0.03 높인다.
> 2. 국소 단독(A1), 자기 신호 gate 단독(A2x), 일치 gate(CTU), 같은 계산량의 앙상블(F2)보다 낫다.
> 3. 보통 대상과 '부재 후 재등장' 상황에서 회귀하지 않는다.

**Proposed improvement mechanism**
1. **배율 (1회):** s = clamp(prompt box 긴 변 / 0.25, min(H,W)/4, min(H,W)). s ≥ min(H,W)이면 crop을 쓰지 않는다(= P5).
2. **두 상태 독립 진행 (메모리 교환 없음):**
   - G: 전체 frame
   - L: 중심이 직전 출력을 따르는 고정 크기 정사각 crop. 팬만 하는 가상 카메라에 해당한다.
3. **채택 규칙 (frame t):** 다음 네 조건을 모두 만족하면 국소 마스크를 붙여 쓴다. 아니면 전역 마스크를 쓴다.
   - `score_L > 0`
   - `m_L ≠ ∅`
   - 내부 경계 미접촉
   - **`score_G > 0`**
4. **거부된 frame의 crop 이동:** 국소 출력이 거부된 frame에서는 출력이 전역 마스크다. 따라서 다음 crop 중심도 전역 마스크를 따른다(재획득 경로).
5. **존재 판단의 비대칭 활용 (SGGL-V 가설):**
   - 극소 대상의 **분할 품질**은 국소 view가 더 낫다.
   - **'지금 대상이 화면에 있는가'**에 대해서는 문맥을 가진 전역 view를 거부권으로 쓴다.

**Why this topic**
- **문제의 크기:** 공식 SAM 2는 극소 대상에서 P5보다 −0.24다. 크기 의존 실패 중 가장 크다.
- **유일한 생존 방향:** M4.5–M6.1에서 다른 모든 학습 없는 경로가 실패했다. 경량 학습 head는 결론을 내지 못했다.
- **계산량과 무관한 이득:** 같은 2× 계산의 F2 대비 +0.018 [+0.009, +0.026].
- **실패 모드를 측정했고 막을 수 있었다:** 진짜 부재 뒤 국소 view가 확신을 갖고 잘못 재획득하는 실패를 측정했다. 단순한 교차 view 신뢰도 규칙이 이를 막았다.

**Evidence contradicting it**
- **관문 미달:** 사전 관문 +0.03(작은 객체)에 개발과 복제 모두 미달했다.
- **사후 근거:** 거부권은 **복제 세트에서 실패를 보고 만든 것**이다. 복제 세트의 +0.020은 독립 근거가 아니다. 사전 등록 지표는 개발 비열등뿐이다.
- **복제 실패:** A2x 자체는 복제 세트에서 CI 기준 복제에 실패했다 (+0.009 [−0.019, +0.032]).
- **거부권의 대가:** 전역 추적기가 작은 대상(0.15–0.7%)을 놓친 경우 이득을 버린다. A2x 대비 dog-gooses obj5 −0.056, lady-running −0.019, scooter-board −0.017, kite-surf obj2 −0.013이며, 이것이 전부다.
- **거부권의 이득은 한 객체뿐:** miami-surf obj5를 빼면 거부권의 순효과는 0 근처이거나 음수다.
- **극소 대상에서는 미검증:** 거부권은 극소 객체(< 0.1%) 7개 어디에서도 발동하지 않았다. 목표 모집단에서의 근거는 어느 쪽으로도 없다.
- **사후 채택과 반복 사용:** A2x는 M6에서 사후에 채택되었다. 같은 개발 영상을 여러 번 보았다.
- **효과 범위:** 전체 J&F 효과는 +0.004로 작다. 보통 객체에는 효과가 없다.
- **극소 대상 표본:** 개발 3개 / 영상 2개, 복제 4개 / 영상 3개뿐이다.
- **다른 세트:** SegTrack birdfall −0.023, PUMaVOS A +0.0015.
- **비용:** crop 적용 객체에서 지연이 2.1배다.

**Novelty**
- **이미 알려진 것:**
  - 병렬 전역–국소 + 선택: CTU
  - 적응 crop + 복구: AdaSAM2
  - 장기 추적의 국소 탐색 + 전역 재탐지·검증: LTMU, SPLT, GlobalTrack, Siam R-CNN. **원문 미확인.**
  - 존재 점수로 메모리와 출력을 제어: DAM4SAM, StreamDAM
  - slicing 추론: SAHI. **원문 미확인.**
- **주장 가능한 기여 (점진적):**
  1. 극소 대상 VOS에서 '분할은 국소 view, 존재 판단은 전역 view'라는 **비대칭 신뢰도 규칙**과, 그것이 막는 실패(확신에 찬 국소 오재획득)의 측정
  2. 일치 gate(CTU), 계산량 대조(F2), 선택 상한 분석
  3. mask VOS 크기 분층 평가

**지시서의 신뢰도·선택 대체 방향과의 관계:**
- 지시서는 '배율 인식 신뢰도 추정이 더 잘 고른다'는 가설을 제시했다. Track D에서 예측 IoU 기반 보정은 현재 후보 사이의 선택을 개선하지 못했다.
- 그러나 복제에서 드러난 실패는 바로 **신뢰도 문제**였다.
- 측정된 해법도 예측 IoU가 아니라 **교차 view 존재 일관성**이었다.
- 따라서 최종 방향은 지시서의 '전역–국소 신뢰도와 선택'과 같은 큰 방향이다. 다만 검증된 신뢰도 신호가 다르다.

## 2. 다음 단계와 기각 조건

**기각 조건** (M7 사전 등록에 숫자 그대로 고정):
1. **효과 부족:** 새 극소 대상 개발 절반에서 SGGL-V 극소 객체 ΔJ&F < +0.03, 또는 영상 CI 하한 ≤ 0.
2. **차별성 없음:** SGGL-V − F2, 또는 SGGL-V − CTU 원형의 영상 CI가 0을 포함.
3. **회귀:** crop 적용 보통 객체 평균 < −0.005, 또는 −0.01보다 나빠진 객체가 20% 이상.
4. **거부권 효과 (이득 쪽):** '부재 후 재등장' 사건이 5개 이상인데, SGGL-V가 SGGL보다 그 사건들의 첫 5 frame J를 개선하지 못한다. 이 경우 거부권을 뺀다.
4b. **거부권 효과 (대가 쪽):** 극소 객체에서 SGGL-V − SGGL < −0.005이면 거부권을 뺀다. 대상이 보이는데 전역 score ≤ 0인 frame 수를 함께 보고한다.
5. **(W arm)** 되쓰기 판정: SGGL-V + W − SGGL-V ≤ 0, 또는 붕괴(객체 −0.1 이하)가 한 번이라도 발생.

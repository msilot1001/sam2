**Research title**
- **KO:** 극소 대상 비디오 객체 분할을 위한 자기 신호 gate 전역–국소 SAM 2 추론 (SGGL)
- **EN:** Self-Gated Global–Local Inference for Tiny-Target Video Object Segmentation with SAM 2 (SGGL)

M7에서 시험할 확장(제목에는 넣지 않음):
- 단방향 국소→전역 메모리 되쓰기 (W)
- 신뢰도로 되쓰기 여부를 정하는 변형

**Research question**
> 독립적인 전체 frame SAM 2 상태와 고정 객체 상대 배율의 crop SAM 2 상태를 함께 돌리고, **crop 상태 자신의 신호**(object score, 내부 경계 접촉)로 frame마다 출력을 고르는 학습 없는 추론이 다음 두 조건을 만족하는가?
> 1. 극소 대상(prompt 면적 < 0.1%)의 mask J&F를 P5보다 ≥ +0.03 높인다. 보통 대상은 회귀시키지 않는다.
> 2. 같은 계산량의 일반 앙상블과 최근접 선행연구의 일치 gate보다 낫다.

**Proposed improvement mechanism**
1. **배율:** 첫 frame 마스크 box 긴 변의 4배로 crop 한 변 s를 한 번 정한다(최소 짧은 변의 1/4).
   - s가 짧은 변 이상이면 crop을 쓰지 않는다. 이 경우 P5와 정확히 같다.
2. **국소 상태 L:** 팬만 하는 가상 카메라 영상을 따로 추적한다. 메모리는 crop 좌표에만 있다.
3. **gate:** frame마다 다음을 모두 만족하면 국소 마스크를 붙여 쓴다. 하나라도 어기면 전역 마스크를 쓴다.
   - crop object score > 0
   - 마스크가 비어 있지 않음
   - 마스크가 내부 crop 경계에 닿지 않음
4. **crop 중심:** 출력 box 중심을 따른다. 국소 출력이 거부되면 전역 출력 쪽으로 crop이 이동해 재획득한다.
5. **(M7 ablation) W:** 채택된 국소 마스크를 전역 메모리에 되쓴다. 단방향만 허용한다.

**Why this topic**
- **문제의 크기:** SAM 2 공식 모델은 극소 대상에서 P5보다 −0.24다. 크기 의존 실패 중 가장 크다.
- **유일한 생존자:**
  - M4.5–M6.1에서 시험한 다른 학습 없는 경로는 효과가 없거나 해로웠다: 메모리 선택, gate 보정, 국소 재분할, flip 앙상블.
  - 경량 학습 head는 결론을 내지 못했다.
- **세 조건:** 이 방향만 개발 데이터에서 일관된 양의 효과, 계산량 대조 우위, 선행연구 gate 대비 우위를 함께 보였다.

**Evidence supporting it** (DAVIS val + PUMaVOS B: 67개 객체 / 영상 36개. crop 적용 16개. P5 대비. 영상 bootstrap CI)

**Evidence contradicting it**
- **관문 미달:** 사전 관문 +0.03(작은 객체)에 미달했다. 그런데도 도전자에게는 '현직 + 차이'를 요구했다. 기준이 비대칭이었다는 점을 인정한다.
- **사후 채택과 반복 사용:** A2x는 M6 사후 탐색에서 나왔다. 같은 영상 10개를 약 15번 보았으므로 효과가 부풀려졌을 수 있다.
- **적은 효과:** 전체 J&F 효과는 +0.004로 작다. 오차의 대부분인 보통 객체에는 효과가 없다.
- **다른 세트에서의 약한 결과:**
  - SegTrack birdfall(작은 객체) −0.023
  - SegTrack 전체 −0.0002
  - PUMaVOS A +0.0015
- **비용:** crop 적용 객체에서 지연이 2.1배다.
- **자기 신호 gate의 근거 범위:** 우위는 CTU의 수용 규칙 하나(우리가 고른 γ = 0.5)에 대해서만 측정했다. CTU 원형(H/4, H/2 병렬)은 재현하지 않았다.

**Novelty**
- **이미 알려진 것:**
  - 병렬 전역–국소 + 선택: CTU 학사논문
  - 적응 crop과 복구: AdaSAM2
  - 장기 추적의 국소 탐색 + 전역 재탐지: LTMU, SPLT, GlobalTrack, Siam R-CNN. **검토자 지식 기반이며 원문은 미확인.**
  - 작은 객체를 위한 slicing 추론: SAHI. **원문 미확인.**
  - 추적기 출력으로 SAM 재분할: HQTrack
  - 정제 마스크를 메모리에 되쓰기: Track Anything
- **주장 가능한 기여 (점진적):**
  1. 극소 대상에서 '전체 frame과의 일치' 대신 crop 상태 자기 신호로 채택하는 gate
  2. 계산량 대조(F2)와 선택 상한 분석
  3. mask VOS(J&F, 크기 분층) 평가
  4. (M7에서 확인되면) 단방향 되쓰기와 그 방향성
- **위험:** VOTS 참가 추적기 부록과 위 장기 추적 문헌을 읽어 직접 선례 여부를 확인해야 한다(TASK-M7-001).

**Main experiment**
- 새 극소 대상 mask VOS 세트(승인 필요)를 영상 단위로 개발 / 확인 절반으로 사전 분할한다.
- **개발 절반 기각 관문:** 비교 arm은 B1, SGGL(A2x), CTU 원형, F2, 그리고 ablation으로 SGGL + W와 SGGL + 신뢰도 gate W.
  - SGGL 극소 객체 ≥ +0.03
  - SGGL − F2, SGGL − CTU 원형의 영상 CI > 0
  - 보통 객체 회귀 없음 (crop 적용 객체만 집계)
- 통과하면 확인 절반과 PUMaVOS C를 1회 실행한다.

**Confidence: PROVISIONAL**

**신뢰도·선택 대체 가설에 대해 (지시서의 fallback):**
- **Track D 결과:** 현재 후보(B1 vs A1) 사이에서 고르는 일에는 여지가 거의 없다. 사후 선택 oracle이 기존 gate보다 +0.0023 높을 뿐이고, 보정 gate는 −0.0016이었다.
- 즉 '배율 인식 신뢰도 추정이 고정 gate보다 **잘 고른다**'는 가설은 이 데이터에서 성립할 여지가 없었다.
- 다만 신뢰도가 쓸모 있을 수 있는 **다른 용도**는 시험하지 않았다.
  - 되쓰기를 할지 말지 결정하기
  - billie_shoes처럼 확신에 찬 잘못된 추적 감지하기
- 그래서 이 대체 가설을 버리지 않고 M7의 **'신뢰도 gate 되쓰기' arm**으로 옮긴다.
- 되쓰기를 지지하는 근거(+0.0022)도 이 가설을 반대하는 근거보다 강하지 않다는 점을 인정한다.

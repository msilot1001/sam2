# M6.1 실험 비교: 현직(A2x)과 도전자

**기준과 집계:**
- 비교 기준은 모두 P5(B1)다. 단위는 객체이고, 객체 내 모든 평가 frame을 평균한다. prompt frame은 제외한다.
- CI는 영상 단위 bootstrap(2,000회)이다.
- '관문 세트'는 DAVIS val + PUMaVOS B다. 작은 객체 15개(영상 10개)가 여기에 속한다.
- crop을 적용하지 않은 객체는 규칙상 B1과 같으므로 Δ = 0으로 넣는다.

**개선 영역별 요약:**
- **이미지 분할:**
  - 단일 frame에서 GT box 이미지 oracle은 crop 배율로 +0.022 오른다(M6).
  - 학습 head는 이미지 수준에서도 개선하지 못했다(작은 객체 −0.009).
- **영상 분할, 극소 객체 (< 0.1%, 3개, 영상 2개):** A2x +0.036이 가장 크다. 표본이 매우 작다.
- **영상 분할, 작은 객체 (0.1–1%, 12개):** A2x +0.013, A3 +0.014.
- **다른 세트:** SegTrack birdfall(작은 객체)은 A2x와 A3 모두 −0.023이다. SegTrack 전체 −0.0002, PUMaVOS A +0.0015.
- **표본:** 관문 세트 67개 중 51개는 규칙상 crop이 없어 Δ = 0이다. A2x가 개선한 12개 객체는 영상 7개에 있다.
- **영상 분할, 보통 객체 (52개):** 어떤 방법도 의미 있는 변화가 없다(A2x +0.0003, head −0.003 수준).
- **전체 데이터셋 정확도:**
  - A2x +0.004 (관문 세트), +0.003 (전체 개발 100개).
  - 이 값은 거의 모두 작은 객체 몇 개에서 나온다.

## 2. 비용 대조: F2 (수평 flip 2× 앙상블)

**설정:** 원본과 좌우 반전 영상에 독립적인 P5 상태를 하나씩 둔다. 두 확률을 평균한 뒤 0.5 이상이면 전경으로 본다. A2x와 같은 2× 계산이다.

**사전 판정 규칙 적용:**
- **incumbent_specific:** A2x − F2(작은 객체) ≥ 0.005 → **충족** (+0.018). 즉 A2x의 이득은 2× 계산량이 아니라 **전역–국소 메커니즘**에서 온다.
- **F2_as_challenger:** F2 전체 ≥ A2x + 0.003 → **불충족.**

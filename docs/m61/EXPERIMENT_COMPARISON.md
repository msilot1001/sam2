# M6.1 실험 비교: 현직(A2x)과 도전자

**기준과 집계:**
- 비교 기준은 모두 P5(B1)다. 단위는 객체이고, 객체 내 모든 평가 frame을 평균한다. prompt frame은 제외한다.
- CI는 영상 단위 bootstrap(2,000회)이다.
- '관문 세트'는 DAVIS val + PUMaVOS B다. 작은 객체 15개(영상 10개)가 여기에 속한다.
- crop을 적용하지 않은 객체는 규칙상 B1과 같으므로 Δ = 0으로 넣는다.

## 4. 복제 (DAVIS train crop 객체 43개 / 영상 23개)

**설정과 성격:**
- **대상:** DAVIS 2017 train에서 A1 규칙이 crop하는 객체 43개 / 영상 23개(작은 객체 41개 / 영상 22개, 극소 4개 / 영상 3개).
- **코드와 파라미터:** 개발 세트와 같다.
- **기준:** 같은 영상의 B1 로그(Track D 적합에 쓴 것)
- **독립성:** A2x와 A3 설계에는 쓰이지 않은 영상이다. 다만 SAM 2 학습 데이터와 겹칠 수 있다.
- **원자료:** `outputs/milestone61/replication/replication_report.json`, `replication_per_unit.csv`

**사전 규칙 판정:**
- **'A2x 복제'(CI 하한 > 0): 실패.** 효과 방향은 같지만 CI가 0을 포함한다.
  - 넓은 CI는 객체 하나 때문이다. miami-surf obj5에서 A2x와 A3 모두 −0.477이다.
  - (사후, 사전 등록 아님) 영상 평균에 대한 Wilcoxon 검정은 p = 0.0003이다.
- **'A3 − A2x ≥ 0': 충족** (+0.004).

**새로 발견한 실패 모드 (miami-surf obj5):**
1. frame 12–23에서 대상이 실제로 사라진다(GT 비어 있음). 두 추적기 모두 부재로 판단하고 J = 1이다.
2. frame 24 무렵 **국소 추적기가 다른 물체를 높은 확신으로 다시 잡는다**(crop object score 최대 7.8).
3. 전역 추적기는 계속 올바르게 부재로 판단한다(score < 0, J_G = 1.0).
4. self gate가 crop을 약 35 frame 채택해 J = 0이 된다.

- CTU 일치 gate도 전역 마스크가 비어 있으면 검사를 건너뛰므로 막지 못한다.
- 개발 세트의 crop 객체에는 이런 '진짜 부재 후 재등장'이 거의 없어서 Track D가 이 여지를 볼 수 없었다.

## 5. 교차 view 존재 거부권 (A2v, 5회차, 탐색)

**설정:**
- **규칙:** A2x의 self gate에 '전역 object score > 0'을 추가한다. 국소 출력은 전역 추적기도 대상이 있다고 볼 때만 채택한다.
- **사전 등록:** `outputs/milestone61/preregistration_r5.json`, 커밋 `733ebf6`
- **성격:** 복제 세트에서 발견한 실패를 보고 만든 규칙이므로, 복제 세트 결과는 독립 근거가 아니다.
- **원자료:** `outputs/milestone61/veto_report.json`, `trackA/a2v_dev_per_unit.csv`, `replication/a2v_per_unit.csv`

| 세트 | A2x | A2v | A2v − A2x | 사전 판정 |
|---|---|---|---|---|
| 개발 작은 객체 (15 / 영상 10, 사전 지표) | +0.0177 | +0.0168 | **−0.0009** (적용 13개 CI [−0.004, 0.0]) | 비열등(≥ −0.003) **충족**. 바뀐 객체는 kite-surf obj2 −0.013뿐 |
| 복제 작은 객체 (41 / 영상 22, 기술 통계) | +0.009 [−0.019, +0.032] | **+0.020** [+0.011, +0.029], 26 ↑ / 2 ↓ | +0.010 [−0.005, +0.032] | miami-surf obj5 −0.477 → **+0.001** (≥ −0.05 충족) |

**대가 (A2x보다 0.01 넘게 나빠진 객체):**

| 객체 | A2v − A2x |
|---|---|
| dog-gooses obj5 | −0.056 |
| lady-running obj2 | −0.019 |
| scooter-board obj2 | −0.017 |
| (개발) kite-surf obj2 | −0.013 |

- 모두 '전역 추적기는 작은 대상(0.15–0.7%)을 놓쳤는데 crop은 맞게 추적하던' 경우다.
- **이득은 한 객체뿐:** miami-surf obj5를 빼면 A2v − A2x = −0.0015 [−0.005, +0.001]이다.
- **극소 대상 미발동:** 극소 객체에서는 거부권이 한 번도 발동하지 않았다.
- 거부권은 이 경우의 이득을 버린다.

**해석:**
- 국소 추적기는 진짜 부재 뒤에 다른 물체를 높은 확신으로 다시 잡을 수 있다. 이것이 A2x의 가장 큰 실패(−0.48)다.
- **전역 view의 존재 판단**은 이를 막는 단순하고 측정된 신뢰도 신호다.
- 반대로 전역 view가 극소 대상을 놓치는 경우에는 대가를 치른다.
- 따라서 다음 단계의 핵심 질문은 '언제 어느 view의 존재 판단을 믿을 것인가'다. 지시서의 신뢰도·선택 방향과 같은 질문이지만, 신뢰도 신호는 예측 IoU가 아니라 **교차 view 존재 일관성**이다.
- 후보 개선(M7): '부재 후 재등장 순간'에만 거부권 적용, 또는 거부권이 일정 frame 이상 이어질 때만 적용.

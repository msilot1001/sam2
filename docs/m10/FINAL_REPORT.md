## 0. 요약

1. SGGL 손실에서 회복할 수 있는 몫은 **하나의 기제**에 모여 있다.
   - 매 frame SAM 2가 내놓는 원시 가설(G 3개, L 3개, 빈 mask) 중 무엇을 고르느냐(존재 판단 포함)가 출발점이다.
   - 그 선택이 기억에 기록되면서 증폭된다.
   - 이 기제는 MOSEv2·VOST에서 견고하다(영상 ↑43/↓0, ↑19/↓0, CI 하한 ≥ +0.10). LVOS v2는 일반화 근거가 약하다(OR8 상위 2영상 비중 0.59).
2. **기억은 오류가 시작되는 곳이 아니라 이어지는 곳이다.**
   - 완벽한 기억(OR8)에서도 이탈 시작 횟수는 거의 같다(106→92, 140→124).
   - 바뀌는 것은 지속 길이다(4.2→1.6, 9.7→1.6 frame).
3. **GT로 고른 상한은 크다.**

   | 조건 | MOSEv2 | VOST |
   |---|---|---|
   | GT로 골라 출력 + 기억에 씀 (OR5M) | +0.170 | +0.299 |
   | GT가 있는 frame에서만 | +0.112 | +0.274 |

   MOSEv2 이득의 1/3(+0.057)은 존재 판단(빈 mask 선택)에서 나온다. 존재 판단은 M9에서 반증된 문제다.
4. **GT 없이 고를 수 있는가?** 사전 등록한 오프라인 관문(수정 5)에서 **다섯 규칙 모두 불통과**했다.
   - 규칙: 예측 IoU, 외형 cosine, 시간·view 일관성, 합성, 로지스틱 회귀.
   - 합동 스위치 정밀도가 0.22–0.40에 그쳤다(기준 0.70).
   - 독립 서브에이전트(Fable)가 원자료로 따로 구현해 같은 수치를 재현했다.
   - **학습한 head(수정 10)도 불통과했다.** 동결 SAM 2의 가설별 스칼라 14개와 decoder token을 입력으로 쓴 MLP다. 두 회차 모두 τ\*에 닿지 못했다.
   - **같은 데이터셋에서 학습해도(수정 11, 진단) 합동 최대 정밀도가 0.41이다.** 원시 예측 IoU는 0.39다.
5. **결론:** 이 연구가 측정한 신호로는 동결 SAM 2.1 tiny 위의 wrapper가 이 병목에 닿지 못한다.
   - crop 기하(7–13%), 기억 기록 거부(10–20%), 모델 크기 교체(유의하지 않음)는 상한 자체가 작다.
   - 상한이 큰 쪽(선택 → 기억)은 GT 없는 신호가 없다.
6. **기준선(수정 9):** 공식 SAM 2.1(B0) 대비 SGGL은 MOSEv2 +0.054 [+0.009, +0.109], VOST −0.036 [−0.081, −0.002], LVOS v2 +0.012 [−0.069, +0.126]이다.
   - P5(prompt 기억만)의 몫은 +0.002–0.013으로 작다. SGGL의 이득과 손해는 L view 쪽에서 나온다.
   - 극소 단위에서는 MOSEv2 +0.121, VOST −0.133, LVOS −0.068이다.

## 4. GT 없는 선택기: 오프라인 관문 (수정 5)

**사전 기준 (외부 검토 11d를 그대로 채택)**
- **범위:** SGGL 출력이 비어 있지 않은 frame에서만, 6개 원시 가설 중에서 고른다. 존재 판단은 건드리지 않는다.
- **스위치 조건:** 규칙 점수가 SAM 2 자신의 선택보다 τ 이상 높을 때만 바꾼다.
- **τ\*:** MOSEv2와 VOST를 합친 스위치 정밀도가 0.70에 도달하는 τ.
- **통과 조건 (τ\*에서 MOSEv2·VOST 각각):** ΔJ CI 하한 > 0, 정밀도 ≥ 0.6, 이탈 frame ΔJ > 0, 맞던 frame ΔJ ≥ −0.005.

**입력:** OR0F. OR0와 같은 궤적에 가설별 신호를 함께 기록했다(109단위). 신호는 예측 IoU, 면적, 직전 출력과의 IoU·거리, 다른 view와의 IoU, frame 0 외형 cosine이다.

| 규칙 | 합동 정밀도 (τ 전 범위) | τ=0 ΔJ (GT 있음): MOSEv2 / VOST / LVOS | 판정 |
|---|---|---|---|
| R_piou (예측 IoU, 두 view 통합) | 0.34–0.39 | −0.003 / **+0.030** / **+0.027** | FAIL (τ\* 없음) |
| R_anchor (IoU + cosine + 교차 view) | 0.31–0.48 | −0.022 / +0.021 / −0.032 | FAIL |
| R_lr (로지스틱, 영상 교차 적합) | 0.29–0.41 | −0.009 / +0.023 / +0.018 | FAIL |
| R_sum4 (+ 직전 출력 신호) | 0.28–0.33 | −0.024 / −0.006 / −0.004 | FAIL |
| R_cos (frame 0 외형) | 0.22–0.26 | −0.134 / −0.041 / −0.134 | FAIL |

**독립 검증 (Fable 서브에이전트)**
- 사전 등록 문서와 원자료만 보고, 판정 코드를 읽기 전에 따로 구현했다. 같은 수치가 나왔다.
- 가설 매핑은 활성 frame 10,894개 전부에서 정확했다. 데이터 누수나 잘못된 결합은 없었고, 판정 코드 버그도 찾지 못했다.
- 동점(둘 다 J = 0)을 빼도 정밀도는 최대 0.62에 그쳤다(스위치 200회 미만).
- 완벽한 선택기라면 활성 frame의 60–74%에서 더 나은 가설을 고를 수 있다. 평균 J 이득은 0.08–0.12다. 그 절반은 **같은 view 안의 다른 가설**인데, 이를 정밀도 약 0.4 이상으로 잡는 규칙은 없었다.
- R_piou는 view 안에서는 SAM 2와 똑같이 고른다. 사실상 G/L view만 바꾸는 규칙이다. VOST·LVOS에서는 τ=0일 때 CI 하한이 0보다 크지만, 사전 기준은 통과하지 못한다.

**결론:** 사전 기준에 따라 온라인 검증기 arm은 실행하지 않는다. 판정은 "현재 신호로는 GT 없는 선택기에 도달할 수 없다"이다(M9 결정 트리 Q1의 아래 가지).

## 7. 고찰

**세 번의 실패는 같은 입력에서 없는 정보를 찾은 것이다.** 손으로 만든 점수 규칙(수정 5), 두 view 불일치 조건부 전환(수정 6·8), 그 위에서 학습한 head(수정 10–11)는 모두 같은 입력을 썼다. 동결 SAM 2.1 tiny가 매 frame 내놓는 6개 가설과 그 부산물(예측 IoU, mask, decoder token, 직전 출력·다른 view·frame 0 prototype과의 관계)이다. 입력을 다루는 방식은 규칙에서 조건, 학습으로 점점 강해졌지만, 합동 스위치 정밀도는 0.22–0.45를 벗어나지 못했다. 학습 head는 원시 예측 IoU(0.39)를 넘지 못했고, 라벨을 섞은 영 대조와의 차이도 H1에서 0.05–0.13, H2에서는 거의 없었다. 학습 데이터를 늘려도, 같은 데이터셋에서 학습해도 나아지지 않았다. 그래서 이를 선택자를 만드는 방식의 문제가 아니라, 맞는 가설과 틀린 가설을 가르는 정보가 이 입력 안에 거의 없다는 뜻으로 읽는다. SAM 2의 예측 IoU와 token은 자기 mask가 '그럴듯한 물체'인지는 말해 주지만, 그것이 '주석된 그 대상'인지는 말해 주지 않는다. oracle의 큰 상한(OR5M +0.170 / +0.299)은 GT가 바로 그 빠진 정보를 공급해서 생긴다. 이것은 증명이 아니다. head 용량과 학습 영상 수(36–63개)가 작아, 더 큰 모델과 데이터라면 정보를 꺼낼 가능성이 남는다. 그래도 이 결과대로라면 다음 시도는 고르는 방법을 더 다듬는 것이 아니라 새로운 정보원을 들이는 것이어야 한다. 예를 들면 대상 신원을 따로 유지하는 외부 표현, 다른 모델, 사용자 입력이다.

**정리 방향 (사용자 결정, 2026-10-16):** conf는 돌리지 않는다. 논문은 세 부분으로 정리한다.
1. 공식 기준선 대비 SGGL의 위치(1절, 수정 9)
2. oracle 분해와 기제(2–3절)
3. GT 없는 선택의 부정 결과(4절, 7절)

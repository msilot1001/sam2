1. 프로젝트 배경
----------------------------------------------------------------
목표
  - 작은·극소 객체 semi-supervised VOS. 첫 frame mask가 주어지면 이후 frame을 분할한다.
  - 기반 모델은 동결된 SAM 2.1 Hiera-Tiny(FP32)이며 학습하지 않는다.
  - 그 위에 얹는 추론 wrapper로 성능을 올린다.

현재 기준 시스템: SGGL (M6 이후 계속 1위)
  - G: 전체 frame SAM 2 상태(video predictor)
  - L: 대상 주변의 정사각 crop SAM 2 상태
      · crop 변 = 첫 frame 대상 긴 변 / 0.25, 하한 min(H,W)/4
      · crop 중심은 이전 출력을 따라간다
  - 자기 게이트: L의 점수 > 0이고 L mask가 crop 가장자리에 닿지 않으면 L 출력, 아니면 G 출력
  - 두 상태는 각자 자기 예측을 매 frame 자기 기억(memory bank)에 기록한다(SAM 2 기본 동작)

지금까지 실패하고 중단한 방향
  - M7: mask 융합, 동결 특징 학습 head, 기억 반사실 실험, 조합
  - M8 → M9: crop 위치 운동 운반(FLOWVEL, PCCARRY)
      · DAVIS 계열에서는 이득이 있었다
      · 새 데이터에서는 MOSEv2 −0.014 (CI < 0), VOST +0.005, LVOS −0.002
  - M9: crop 크기 조절(SCALE)
      · 사전 기준 불통과
      · 정보 없는 흔들림(NULLJIT)과 구분되지 않음
  - M9: L 점수 기반 기권(CONSENSUS) — 반증됨(conf −0.050)
  - M8: 후보 생성 + 순위화 rescue
      · 순위화기 AUC 0.57–0.65
      · held-out 순이득 ≤ 0
  - M9 출력 관계 분석: 놓친 손실의 54% / 68% / 68%(MOSEv2 / VOST / LVOS v2)가 '출력이 대상 밖'

M10의 목적
  - GT로 병목 하나씩만 완벽하게 고치는 oracle 개입 실험을 한다.
  - 회복량으로 병목 순위를 정한다.

평가 지표
  - 주 지표: 데이터셋별 영상 동일 가중 ΔJ&F(arm − OR0). 단위 평균 → 영상 평균.
  - 95% CI: 영상 단위 bootstrap 10,000회.
  - 그 밖에 LOVO, 상위 2영상 비중, 영상 ↑/↓(±0.01) 수.

기준선 재현
  - OR0는 같은 Pod(RTX 4090)에서 다시 돌렸다.
  - M9 SGGL과 frame 단위로 완전히 일치한다(8,425 frame, |Δ| = 0).

공통 규칙
  - 모든 oracle의 출력은 SAM 2가 예측한 mask이거나 빈 mask다. GT mask를 출력으로 복사하지 않는다.
  - '맞음'은 J ≥ 0.5다(GT와 출력이 둘 다 비어도 맞음).


3. Oracle 정의 (코드: scripts/m10.py)
----------------------------------------------------------------
"후보 7개": 각 frame에서 SAM 2가 이미 만드는 것
  - G 디코더 원시 multimask 가설 3개 (존재 점수로 지우기 전)
  - L 원시 가설 3개
  - 빈 mask
  GT로 새 후보를 만들지 않는다.

  OR1off  존재 판단 (오프라인): GT가 없는 frame의 출력을 비움
  OR4     완벽한 기하: L crop 중심과 크기를 그 frame GT로 설정 (비인과)
  OR5off  후보 선택 (오프라인): frame마다 7개 중 GT J가 최대인 후보. 사후 계산, 미래 영향 없음
  OR5S    후보 선택 (온라인, 출력만): 위 선택을 출력. crop이 출력을 따라간다. 기억은 SAM 2 원래대로
  OR5M    후보 선택 + 기억 (온라인)
          - 출력 = GT 최선 후보
          - 각 view의 frame 기억을 그 view의 GT 최선 원시 가설로 다시 부호화(SAM 2 mask 입력 경로)
          - GT mask는 쓰지 않는다
  OR6off  대상 영역 판별 (오프라인): 맞으면 유지 → 다른 view가 맞으면 교체 → 대상 밖(precision < 0.5)이면 기권
  OR7     기억 기록 허용: view 예측이 맞을 때만 그 view 기억에 기록. 막힌 자리는 이전 frame으로 채운다.
          출력은 SGGL 그대로
  OR7W    대상 밖 예측(precision < 0.5)만 기록 차단
  OR7R    대조: OR7과 같은 개수를 무작위로 차단
  OR8     완벽한 기억: frame t 출력 뒤, 각 view의 frame t 기억을 GT mask로 다시 부호화. 출력에는 GT를 쓰지 않음
  OR8K10  OR8을 10 frame마다만 적용 (드문 교정)
  OR9     분할 용량: SAM 2 이미지 모드에 frame마다 GT box prompt (추적 아님)
  C58     OR5S + OR8
  C75     OR5S + OR7: GT mask 없이 '맞는 후보 선택 + 틀린 예측 기록 거부'
  보류(사용자 결정): OR2/OR3(위치·크기 단독), OR1M, OR6(온라인), OR8C0, C47, C48

9. 지금까지의 결론 (잠정)과 Deep Research에 묻는 것
----------------------------------------------------------------
잠정 결론
  (1) 가장 큰 회복 가능한 병목은 '기억에 들어가는 내용'이다.
      - 완벽한 기억 OR8: 손실의 54–66% 회복
      - 그 대부분은 SAM 2가 이미 만든 가설 중 맞는 것을 고르고 그것을 기억에 쓰면 얻어진다
        (OR5M 60–62%, GT mask 불필요)
  (2) 기록 거부만 하면(OR7) 10–20%만 회복한다.
      - 같은 개수를 무작위로 막는 대조(OR7R)는 0 또는 음수다. 그러니 '어느 frame을 막는지'가 핵심이다.
      - 틀린 것을 막는 것보다 맞는 가설로 바꿔 쓰는 쪽이 3배 이상 크다.
  (2b) GT mask 없이 '맞는 후보 선택 + 틀린 예측 기록 거부'만 완벽하면(C75) 손실의 44–55%를 회복한다.
       실용 검증기의 상한이다. 선택 + 완벽한 기억(C58)은 76–80%다.
  (3) crop 기하(위치·크기)는 완벽해도 7–13%다 → 중단이 타당.
      모델 크기 확대도 VOST에서 유의한 이득이 없다.
  (4) 존재 판단(false_present)은 MOSEv2에서만 크다(손실의 24%, 출력 oracle +0.057).
  (5) 디코더 multimask 가설 선택 오류가 실제로 있다.
      - 예: L의 가설 0이 J 0.93인데 SAM 2가 예측 IoU로 가설 2를 고름
      - 출력 view의 선택 오류(own_view_misselect + suppressed)가 OR0 놓친 손실의 23% (MOSEv2) / 8% (VOST) / 19% (LVOS)

다음 단계 후보 (실제로 만들 수 있는 것; GT 없이)
  A. 가설 검증기 + 기억 재부호화 (OR5M의 실용 버전)
     - G·L의 원시 가설 6개(+빈 mask) 중 하나를 GT 없이 고르는 점수 → 출력과 기억에 쓴다
     - 쓸 수 있는 신호: 디코더 예측 IoU, 객체 점수, 직전 출력과의 mask IoU 및 중심 연속성,
       G-L 교차 일치, frame 0과 신뢰 기억의 외형 cosine(M8: AUC 0.65), 운동 예측(Kalman)
  B. 다중 가설 기억 경로 유지 (SAM2Long류 tree / beam). 누적 점수로 경로를 고른다
  C. 신뢰도 기반 기억 기록 + 신뢰 기억 우선 읽기 (OR7의 실용 버전; 상한 10–20%)

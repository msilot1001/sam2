## 2. 처리량

| 구성 | 처리량 |
|---|---|
| Pod, 워커 8개 (OMP 2) | 워커당 약 1.15–1.2 frame/s, 합 약 9–11.5 frame/s, GPU 100% |
| Pod, 1080p MOSEv2 | 프레임당 J&F 계산 4회 × 34 ms가 CPU 비용. 주된 병목은 GPU(1024² 인코더 2회/frame) |
| Ubuntu 2080, 워커 2개 | 합 약 2.2 frame/s (tiny) |

FP32를 유지했다. bf16으로 바꾸면 M9 기준선과의 비트 일치가 깨지기 때문이다.

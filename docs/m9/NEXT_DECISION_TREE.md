# M9 이후 연구 결정 트리

## 출발점 (2026-10-15 M9 종료 시점)

| 항목 | 내용 |
|---|---|
| 현재 기준 시스템 | **SGGL** (변경 없음) |
| FLOWVEL | 일반화 실패. MOSEv2에서 −0.0142 (CI < 0), VOST에서 +0.0046 (CI가 0을 포함). LVOS v2는 FINAL 참고 |
| SCALE | 사전 기준 불통과. 스케일 범주 회복이 18% / 2%로 기준 30%에 못 미침. MOSEv2에서만 영 대조보다 조금 나음 |
| CONSENSUS, PCCARRY | 반증·중단 |
| 주된 실패 | 사전 범주로는 MIXED이고 SCALE이 가장 큼. 출력 관계로 보면 **출력이 대상 밖**이 놓친 손실의 54% (MOSEv2) / 68% (VOST) |
| 측정 문제 | 정보 없는 crop 흔들림(NULLJIT)도 ±0.05 단위 변동을 8–9개씩 만든다. '−0.05 미만 단위 0–1개' 기준은 메커니즘을 가르지 못한다 |
| 봉인 세트 | PUMaVOS C 봉인 유지 |

## 결정 트리

```
Q1. 놓친 frame의 출력이 대상 밖에 있을 때, 그 출력이 '다른 대상'임을 알아볼 신호가 있는가?
    (오프라인 측정만. 메커니즘을 만들기 전에)
    측정: MOSEv2 dev의 '대상 밖' frame vs 맞는 frame에서 출력 영역의 외형 특징
          (SAM 2 image encoder 특징, frame-0 대상과의 cosine, 이전 맞는 frame과의 cosine, 이웃 영역 대비 대조)
          → AUC, 영상 군집 CI
 ├─ AUC ≥ 0.85, 여러 영상(≥ 20)에서 → Q2
 └─ AUC < 0.75 (M9 Stage 1 점수 AUC 0.57–0.65 수준) → 
        SAM 2 tiny 위의 규칙형 wrapper로는 신원 이탈을 고칠 수 없다는 결론 → Q3

Q2. 신원 신호로 '기억 기록 거부'(이탈로 의심되는 frame을 memory bank에 넣지 않음)가 이탈을 줄이는가?
    (DAM4SAM / SAMURAI 류 기억 선택 정책과 같은 계열; M8 결정 트리의 '방해물 → 메모리 기록 정책' 가지)
    사전 등록: arm 1개, NULLJIT 영 대조 동시 실행, 판정은 conf + 다른 데이터셋
    기준: 대상 밖 손실 ≥ 30% 감소, ΔJ&F CI 하한 > 0,
          −0.05 미만 단위 수 ≤ NULLJIT의 같은 단위 수
 ├─ 통과 → 확인 실행 (봉인 세트 C 1회 + LVOS 전체 길이)
 └─ 실패 → Q3

Q3. 기반 모델 용량 문제인가?
    측정: 같은 manifest에서 SAM 2.1 base+ / large SGGL 궤적의 '대상 밖' 손실 비중 비교 (추론만)
 ├─ 큰 모델에서 대상 밖 비중이 크게 줄어듦 → tiny 대상 연구의 기반을 큰 모델로 옮기고, 지연·메모리 비용을 따로 보고
 └─ 줄지 않음 → 이 문제는 SAM 2 계열의 기억 구조 한계. 학습(fine-tuning) 없이 wrapper로 풀 수 있는 범위는 끝났다고 보고 정리
```

## 사전 등록 규칙 수정 (M9에서 배운 것)

- 비회귀 기준은 **NULLJIT 대비**로 쓴다. 예: −0.05 미만 단위 수 ≤ 같은 단위의 NULLJIT 값.
- 판정은 최소 2개 데이터셋에서 한다. LVOS v2는 이제 쓸 수 있다(Pod 볼륨에 압축 보관; 영구 사본은 Ubuntu에 없음 — FINAL 참고).
- 실패 분류에 '출력 관계'(출력 없음 / 대상 밖 / 대상 일부)를 사전 범주로 넣는다. M9에서는 사후 분석이었다.

# 구현 로드맵 (주제 승인 후, 1–2주)

**전제:**
- 사용자가 [`FINAL_RESEARCH_TOPIC_DECISION.md`](FINAL_RESEARCH_TOPIC_DECISION.md)의 잠정 주 방향을 승인해야 시작한다.
- 큰 데이터나 checkpoint를 내려받기 전에는 매번 승인을 받는다.
- master에 병합하지 않는다.
- PUMaVOS C는 단계 7 전까지 열지 않는다.

| 단계 | 일정 | 작업 | 산출물 | 완료 조건 |
|---|---|---|---|---|
| 1 | 1일차 | **극소 대상 데이터 선정 (승인 필요).** SA-V val/test, LVOS v2 val, VOST의 라이선스·크기·mask 공개 여부를 확인한다. prompt 면적 < 0.1%인 객체 수를 센다(GT만 사용, SAM 2 실행 금지) | `docs/m7/DATA.md`, 데이터 선정 manifest | 극소 객체 ≥ 20개, 영상 ≥ 12개 |
| 2 | 1일차 | **분할 고정.** 영상 단위 hash로 개발 / 확인 절반씩 나누고 커밋한다. 기각 조건(결정서 §J)도 숫자 그대로 고정한다 | `outputs/milestone7/manifest.json`, `preregistration.json` | 추론 전 커밋 |
| 3 | 2일차 | `src/spatial/sggl.py`: 두 상태를 한 루프에서 돌리고 gate를 함수로 분리(self / agreement / none). 테스트 4종(명세서 §7) | 코드와 테스트 | identity·인과·격리 테스트 통과. A2x 기록과 출력이 같음 |
| 4 | 2일차 | **CTU 원형 기준선:** H/4, H/2 창 병렬과 일치 gate(γ = 0.5, β = 0.1). 저자 코드가 공개되어 있으면 메모리 처리를 확인한다 | 기준선 arm | DAVIS val 1개 영상 sanity |
| 5 | 3일차 | **기각 관문 실행 (새 개발 절반):** B1, A1, A2c, CTU 원형, SGGL | 객체별 표, 영상 CI | 결정서 §J 1–3 판정. **실패하면 단계 9로** |
| 6 | 4–5일차 | ablation 1–5 (명세서 §6). Hiera-L 검사(ckpt 다운로드 승인 필요) | ablation 보고서 | §J 4 판정 |
| 7 | 6일차 | **확인 1회:** 구현과 파라미터를 고정해 커밋한 뒤 새 확인 절반 + PUMaVOS C를 실행한다. 모든 객체를 보고하고 이후에는 튜닝하지 않는다 | 확인 보고서 | §J 5 판정 |
| 8 | 7–10일차 | 분석: 크기별 효과, 실패 사례, escape / 채택률, 예측 IoU 배율 편향, 지연시간. 논문 초안 | `docs/m7/` 보고서, 그림 | — |
| 9 | (기각 시) | 범위를 F1 진단 연구로 전환하자고 제안하고 승인을 받는다. M4.5–M6 결과로 상한 분석 원고를 쓴다 | 전환 제안서 | 사용자 승인 |

| 단계 | 예상 시간 |
|---|---|
| 단계 5 | arm 5개 × 약 40분 |
| 단계 6 | 약 4시간 |
| 단계 7 | 약 1시간 |

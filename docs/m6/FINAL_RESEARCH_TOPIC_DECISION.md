## 2. 주 추천

### A. 연구 제목

- **KO:** SAM 2의 자기 신호 기반 전역–국소 추론을 이용한 극소 대상 비디오 객체 분할
- **EN:** Self-Gated Global–Local Inference for Tiny-Target Video Object Segmentation with SAM 2

### B. 문제 정의

- SAM 2.1(Hiera-T)은 화면 면적이 매우 작은 대상에서 성능이 급격히 떨어진다.
  - J: < 500 px에서 DAVIS 0.18, PUMaVOS 0.28. 8k–32k px에서는 0.91.
  - 1024 입력에서 이런 대상은 stride-16 특징 몇 개에만 걸친다.
- 이 실패는 메모리 관리로는 고쳐지지 않는다(M5-Pre, M5.6: 메모리 개입이 고친 것은 2/35).
- 입력 배율을 키우면 정지 영상 분할 품질이 오른다(이미지 oracle +0.02, 극소 대상 +0.06–0.13).
- 그러나 단순 crop 추적은 다음 이유로 실패하거나 회귀한다.
  - 빠른 대상이 crop을 벗어난다 (motocross −0.114).
  - 과도한 확대로 문맥이 사라진다 (A1z −0.044).
  - 전체 frame과의 일치로 crop을 검증하는 기존 규칙(CTU)은 전체 frame이 틀릴 때 crop을 버린다.

### C. 연구 질문

> 전체 frame SAM 2 상태와 고정된 객체 상대 배율의 crop SAM 2 상태를 독립적으로 유지하고, **crop 상태 자신의 신호(object score, 내부 경계 접촉)만으로** crop 출력을 채택하는 학습 없는 추론이 다음 두 조건을 만족하는가?
> 1. **극소 대상**(prompt 면적 < 0.1%)의 mask J&F를 P5 기준선보다 ≥ +0.03 높인다. 보통 대상은 회귀시키지 않는다.
> 2. 전체 frame과의 **일치**로 채택하는 규칙(CTU)보다 낫다.

### D. 과학적 가설

1. **H-scale:** 극소 대상에서 정지 영상 분할 오차의 상당 부분은 입력 해상도(encoder 토큰 수) 부족 때문이다.
   - 고정 객체 상대 배율의 crop은 이 부족을 줄인다. 근거: 이미지 oracle 증가, lab-coat +0.06.
2. **H-gate:** 전체 frame 예측은 극소 대상에서 자주 틀린다.
   - 그래서 '전체 frame과 일치할 때만 crop 채택' 규칙은 crop이 가장 필요한 frame을 버린다.
   - crop 상태의 object score는 대상이 crop 안에 있는지를 전체 frame과 무관하게 알려 준다.
   - 근거: 채택률 0.89 vs 0.57, A2x − A2c +0.008.
3. **H-safety:** 대상이 crop 밖으로 나가면 crop 상태의 object score가 떨어지거나 마스크가 crop 경계에 닿는다.
   - 이때 전체 frame 출력으로 돌아가면 escape 회귀가 사라진다. 근거: motocross −0.114 → +0.002, 보통 객체 회귀 0.
4. 이 세 가설이 맞다면, 효과는 대상이 작을수록 커져야 한다.
   - 근거는 시사적인 수준이다: ρ = −0.59 (A1, n = 16) / −0.44 (A2x, p = 0.085).

### E. 제안 알고리즘

세부는 [`PROPOSED_ALGORITHM_SPEC.md`](PROPOSED_ALGORITHM_SPEC.md)에 있다. 요약:

**입력과 출력:**
- 입력: RGB frame 열, frame 0의 GT 마스크
- 출력: frame마다 원본 해상도의 이진 마스크

**바꾸는 SAM 2 구성요소:**
- 가중치·모듈은 바꾸지 않는다. **입력 단계(frame 공급)와 출력 선택만** 바꾼다.
- 상태 G: P5 적용 전체 frame
- 상태 L: crop 영상
  - 한 변 s = clamp(prompt box 긴 변 / 0.25, min(H,W)/4, min(H,W))
  - 고정 배율이며 정사각형이다. 1024로 resize한다.

**frame t의 처리 순서:**
1. L의 crop 위치를 c_{t−1}로 정한다. 직전 **융합** 출력 box의 중심이다.
2. G와 L을 각각 한 frame씩 진행한다. 메모리는 서로 섞지 않는다.
3. crop 출력을 채택하는 조건: (L의 object score > 0) ∧ (L 마스크가 비어 있지 않음) ∧ (frame 경계가 아닌 crop 경계에 닿지 않음). 이 조건이면 L 출력을 원본에 붙이고, 아니면 G 출력을 쓴다.
4. c_t = 융합 출력 box의 중심. 출력이 비어 있으면 c_{t−1}을 유지한다.

**적용 범위:**
- s ≥ min(H,W)이면 L을 만들지 않는다(= P5, 정확히 같음).

**인과 제약:**
- GT는 frame 0에서만 쓴다.
- crop 위치는 t−1까지의 출력으로만 정한다.
- frame t는 SAM 2가 요청하는 순간에만 만든다.
- 메모리 좌표 변환은 없다.

**비용:**
- 시간: crop 적용 객체는 약 2배(0.208 → 약 0.43 s/frame), 미적용 객체는 0.
- VRAM: ≤ 1.0 GB (영상 CPU offload).

### F. 새로움 평가: 가장 가까운 연구 3개

| 연구 | 같은 점 | 정확한 차이 | 독창성 위협 |
|---|---|---|---|
| **CTU 학사논문** (Rozumnyi 2025, 미심사, READ) | 학습 없는 SAM2.1 crop 창. 전체 frame과 병렬로 돌린 뒤 frame마다 선택 | **수용 gate:** 자기 신호 vs 전체 frame과의 IoU 일치 **배율:** 객체 상대 고정 1개 vs 이미지 비율 H/4·H/2 **평가:** mask VOS(J&F, 크기 분층) vs VOT **메모리:** 처리 명시 vs 서술 없음 | **높음.** 골격이 같다. 차별점은 gate 하나이고, 측정 차이는 +0.008로 작다 |
| **AdaSAM2** (Sensors 2026, 심사, READ) | 작고 빠른 대상, crop 배율, 실패 시 복구 | 학습 없음 vs RL 정책. 객체 상대 배율 vs 이미지 비율 이산 집합. 전역 상태를 병렬 유지 vs 실패 시 crop 확대. VOS vs VOT | 중간 |
| **SAM2Refiner** (ICCV'25, READ) | 작은·세부 대상의 분할 품질 개선 | 학습 없음, 입력 배율 vs 학습된 1024 정제 head | 중간 (같은 문제를 다른 메커니즘으로 해결. 함께 쓸 수 있음) |

**독창성을 위협하는 겹침 (정직하게):**
- 'crop + 전역 병렬 + 선택'은 새롭지 않다.
- 주장할 수 있는 것은 다음 네 가지뿐이다.
  1. 수용 gate의 차이와 그 효과를 통제 비교로 보인 것
  2. 극소 대상에서 크기 의존 효과를 mask VOS로 측정한 것
  3. 과도한 확대가 정지 영상 분할 자체를 망친다는 것(A1z, oracle 0.782 < 0.819)
  4. SAM 2 예측 IoU가 확대 입력에서 부풀려진다는 것(S1 실패 원인)
- 이것이 '새 방법'보다 **'기존 아이디어의 VOS 재검증 + gate 개선 + 상한 분석'**에 가깝다는 점을 논문에 명시해야 한다.

### H. 벤치마크 프로토콜

**데이터:**
- **개발 (이미 사용):** DAVIS val, PUMaVOS A+B, SegTrack. 결과는 탐색용이며 다시 튜닝하지 않는다.
- **새 극소 대상 개발·확인 세트 (승인 필요):** 공개 mask VOS 데이터에서 prompt 면적 < 0.1%인 객체만 모은다.
  - 후보: SA-V val/test, LVOS v2 val, VOST. 크기·라이선스는 다운로드 전에 확인한다.
  - 영상 단위로 개발 / 확인 절반씩 사전 분할한다.
- **확인 1회:** PUMaVOS C(11개 객체 모두 보고) + 새 세트의 확인 절반.

**기준선:**
- B0(공식), B1(P5)
- A1(crop 단독)
- **A2c(CTU 일치 gate) + CTU 원형(H/4, H/2 창 병렬)**
- (가능하면) AdaSAM2식 이미지 비율 고정 crop

**지표:**
- J&F, J, F, F_strict
- 크기 분층: < 0.1%, 0.1–1%, ≥ 1%
- 실패 구간과 회복
- escape 비율, crop 채택률
- 지연시간, VRAM

**통계:** 영상 단위 bootstrap CI, 짝지은 비교

**ablation:**
1. gate 종류: 자기 신호 / 일치 / 없음
2. 배율 목표: 0.25 / 0.35. clamp 최대 4× / 8×
3. crop 중심 출처: 융합 출력 / crop 출력
4. 경계 접촉 조건 유무
5. Hiera-T / Hiera-L

### J. 위험과 기각 조건

다음 중 하나라도 해당하면 **이 방향을 버린다** (사전 고정, 새 극소 대상 개발 절반 기준):

1. **효과 부족:** 극소 객체(< 0.1%)에서 A2의 ΔJ&F < +0.03, 또는 영상 CI 하한 ≤ 0.
2. **선행연구와 구별 불가:** A2 − A2c(CTU 일치 gate)의 영상 CI가 0을 포함한다. 이 경우 차별점이 사라진다.
3. **회귀:** crop을 적용한 보통 객체 평균 < −0.005(희석 없이 적용 객체만), 또는 −0.01보다 나빠진 객체가 20% 이상.
4. **backbone 의존:** Hiera-L에서 효과가 절반 이하로 줄어든다. 이 경우 Hiera-T의 해상도 부족에 한정된 결과다.
5. **확인 실패:** PUMaVOS C에서 어떤 객체든 −0.02보다 나빠진다.

**기각되었을 때의 대안 (범위 변경을 명시):**
- **F1 진단 연구:** 「SAM 2.1의 학습 없는 추론 단계 개선의 상한: 메모리·prompt·배율·후보·존재 신호」
  - M4.5–M6의 통제 개입과 상한을 체계적으로 정리한다.
  - 내용: 메모리 개입 2/35, P5 학습/추론 불일치, 배율 상한 +0.03, 후보 선택 상한 +0.01, 예측 IoU의 배율 의존 편향.
  - 이 경우 기여는 새 알고리즘이 아니라 **측정과 분석**이다.
  - 사용자의 '알고리즘 개발' 목표와는 다른 범위이므로 그때 다시 승인을 받는다.

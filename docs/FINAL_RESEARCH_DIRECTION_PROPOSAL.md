## 2. 주 방향

**제목:**
- **KO:** 소형·세부 대상 비디오 객체 분할을 위한 SAM 2의 메모리 일관 적응 확대 추론
- **EN:** Memory-Consistent Adaptive Zoom Inference for Small-Target Video Object Segmentation with SAM 2

**겨냥하는 실패 메커니즘:**
- 대상이 frame에서 차지하는 면적이 작으면 성능이 크게 떨어진다.
  - 1024 입력에서 image encoder 최상위 특징은 stride 16(64×64)이고, decoder 출력은 stride 4다.
  - 그래서 500 px 미만 대상은 최상위 특징 기준으로 토큰 수 개에 불과하다.
- 측정된 결손 [관측]:
  - DAVIS: < 500 px J 0.18
  - PUMaVOS: < 500 px J 0.28 (8k–32k 대상은 0.90)
- 메모리 없이 GT box를 준 이미지 oracle도 이런 frame에서 낮다(BC 분류 8개 구간). 즉 **메모리 문제가 아니라 그 크기에서의 표현 문제**다.

## 3. 제안하는 SAM 2 변경

**바꾸는 위치:** SAM 2 가중치는 고정한다. image encoder **입력 단계**와 그 좌표 변환만 바꾸며, video predictor 바깥의 래퍼로 구현한다.

1. **확대 배율 s:** prompt 마스크 면적으로 clip당 한 번 정하고 고정한다. 대상 box가 입력의 일정 비율(예: 짧은 변 기준 25%)을 차지하도록 정한다. 메모리 특징의 크기를 일관되게 유지하기 위해서다.
2. **crop 중심:** 직전 frame의 예측 마스크 중심을 따른다(인과적). crop 크기는 고정한다.
3. **좌표계:** 메모리와 object pointer는 crop 좌표계에서만 유지한다. 원본 좌표로 되돌리는 것은 출력 마스크뿐이다.
4. **되돌림:** object score가 음수이거나 대상이 crop 경계에 닿으면 그 frame은 전체 frame 추론으로 돌아간다. 이 frame의 메모리를 어떻게 다룰지는 ablation으로 정한다.

**기대 메커니즘:**
- 같은 대상이 1.5–3배 많은 encoder 토큰과 decoder 출력 픽셀에 걸친다.
- 그래서 정지 영상 분할 한계(BC)와 출력 해상도 한계(A)가 함께 완화된다.
- 메모리는 일정한 배율로 쌓이므로 확대가 메모리 분포를 흔들지 않는다. M5.5의 guided_mem 실패 원인으로 추정한 '분포 이동'을 피하기 위한 설계다.

**J&F가 오를 것으로 기대하는 근거와 그 한계:**
- [사후 GT] 고정 crop 탐침에서 kite-surf obj2 +0.20, kite-surf obj1·smile +0.09가 나왔다.
- 하지만 lab-coat가 −0.03 ~ −0.05, 영상 전체로는 −0.39까지 나빠졌다.
  - 원인 가설: crop 안의 문맥 손실, 또는 비슷한 주변 물체.
  - **이 악화를 막지 못하면 방향 자체가 기각된다.**

**새로움에 대한 정직한 평가:**
- 'crop해서 추적'은 고전 SOT의 표준 기법이다. 새로움은 그것 자체에 있지 않다.
- 새로울 수 있는 것은 **SAM 2 메모리 은행과 crop 배율·좌표의 상호작용**을 통제 실험으로 밝히고, 그 위에 회귀 없는 규칙을 만드는 것이다.
- 비교 대상: 고정 배율 vs 가변 배율, 되돌림 frame 메모리 포함 vs 제외.
- 이것이 단순 조합 이상의 기여가 되는지는 §6 결과에 달려 있다.

## 5. 검증 가능한 가설

- **H1:** 작은 객체(prompt 면적 < 1%)에서 확대 추론이 B1보다 J&F를 ≥ +0.03 올린다(영상 bootstrap CI 하한 > 0).
- **H2:** 큰 객체에서는 되돌림 규칙 덕분에 회귀가 없다(|ΔJ&F| ≤ 0.005).
- **H3 (메커니즘):** 가변 배율은 고정 배율보다 나쁘다(메모리 크기 불일치 가설). 반대 결과가 나오면 '메모리 일관성'이라는 핵심 주장을 철회한다.
- **H4:** 개선은 미래 frame에서도 유지된다. frame 21 이후 효과가 frame 1–20의 50% 이상이어야 한다.

## 6. 실험 설계와 최소 기각 실험

**데이터:**
- 개발: PUMaVOS B, DAVIS val 작은 객체. 탐색 단계에서 이미 본 데이터다.
- 확인: PUMaVOS C 11개 객체 (한 번만 사용).
- 확장(선택): MOSEv2 일부, 승인 필요.

**기준선:** B0 공식, B1(P5), [사후 GT] 고정 GT crop(상한).

**ablation:**
- 배율 고정 vs 가변
- 되돌림 규칙 유무
- 되돌림 frame의 메모리 포함 vs 제외
- crop 중심 규칙(직전 마스크 vs 직전 box 예측)

**최소 기각 실험 (1일 이내, 학습 없음):**
- 대상: DAVIS val 작은 객체 13개 + PUMaVOS B 6개.
- 비교: B1 vs B1 + 고정 배율 확대(되돌림 포함).
- 하이퍼파라미터: 배율 목표 25%, 되돌림 조건 object score < 0. 사전 고정하며 조정하지 않는다.
- **기각 조건 (어느 하나라도 해당하면 기각):**
  - 작은 객체 ΔJ&F < +0.03
  - 작은 객체의 20% 이상에서 −0.01보다 악화
  - 큰 객체의 평균 회귀 > 0.005

## 8. 위험과 대안

**위험:**
1. 확대가 문맥을 잃게 해서 비슷한 주변 물체를 오인한다. lab-coat에서 이미 관찰됐다.
2. 빠르게 움직이면 crop을 벗어나고, 되돌림이 자주 일어나 메모리가 섞인다.
3. 작은 객체 표본이 적다(DAVIS 13개, PUMaVOS 5개). 결론이 불안정할 수 있다.
4. 선행연구(RL crop 논문)가 생각보다 많이 겹칠 수 있다(원문 미확인).

**대안 (기각 시):**
- **F1:** 범위를 **"SAM 2.1 실패의 원인별 통제 진단 연구"**로 전환한다. M5-Pre부터 M5.6까지의 통제 개입 결과(메모리 개입 95% 무효, 실패의 80%는 GT 재prompt로도 회복 불가, prompt 메모리 해상도의 학습/추론 불일치와 P5)를 체계적인 분석 논문으로 낸다. 이 경우 기여는 새 알고리즘이 아니라 **측정과 진단**이다.
- **F2:** C2(재획득)를 진짜 부재와 마스크 붕괴를 구분하는 진단부터 다시 시작한다. 단, 선행연구가 혼잡하다.

## 9. 입증된 것 vs 입증되지 않은 것

| 구분 | 내용 |
|---|---|
| **실험으로 확립** | 작은 대상 결손 (2개 데이터셋). 실패 구간 28/35는 GT 재prompt로도 10 frame 안에 회복 불가. 배포 가능한 메모리 개입은 2/35만 고침. P5 효과(DAVIS +0.017, PUMaVOS +0.003, 악화 0). 결정론과 재현성 |
| **그럴듯한 메커니즘** | 작은 대상의 encoder/decoder 토큰 부족 (이미지 oracle도 낮음) |
| **검증 안 된 가설** | 확대 추론이 회귀 없이 작은 대상 J&F를 올린다. 고정 배율 메모리 일관성이 중요하다 |
| **공학적 교정 (새로움 아님)** | P5 full-res prompt 메모리 |
| **진짜 새로움** | 아직 없음. §6을 통과해야 주장할 근거가 생긴다 |

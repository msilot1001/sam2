**함의 (실험 전 가설):**
1. 회수 가능한 손실은 크게 두 종류다.
   - 위치형: drone, kite-surf·skate-park의 일부. 대상이 crop 밖에 있다. 전역 탐색과 운동이 필요하다.
   - 표현형: dog-gooses, lady-running. crop 안에서 작아지거나 가려진다. 배율 조절과 prompt가 필요하다.
2. GT 면적이 초기의 수 %인 잔여 조각 frame(약 1/3)은 어떤 생성기로도 J > 0.5로 회수하기 어렵다. 그래서 recall 상한이 낮아진다.
3. 진짜 부재 frame(355)이 GT 있음 frame(131)의 2.7배다. rescue의 거짓 양성 비용은 구조적으로 크다.
   - J 계산 규칙상 GT가 빈 frame에서 빈 출력은 J = 1이다. 거기에 무엇이든 출력하면 J = 0이 된다.
   - 그래서 진짜 부재 frame 하나의 거짓 양성은, 회수 하나의 이득(≈ +0.5~0.8)보다 큰 손실(−1)을 낸다.

**사례별 결론:**

1. **위치형 (drone obj1).**
   - 대상이 crop 밖에 있고 크기는 크다. 전역 외형 매칭(A/B/D)이 거의 전부(38/39)를 찾는다.

   - 후보 생성으로 풀 수 있는 큰 사례는 이것 하나다. 동시 부재 회수 frame(67)의 57%가 이 한 단위에서 나온다.
2. **혼합형 (kite-surf obj2, skate-park obj2).**
   - 전역 매칭은 kite-surf의 절반만 찾고, skate-park은 하나도 찾지 못한다.
   - skate-park은 heatmap 위치에 L crop을 다시 놓을 때(B_att_crop)만 5 frame을 찾는다.
   - 대상이 작아지고 빠르게 움직이는 사례다. M7 M3-vel이 고친 것도 이 유형(빠른 재획득)이다.
3. **가림·축소형 (scooter-board, sheep, miami-surf, disc-jockey, smile).**
   - **어떤 생성기도 회수하지 못한다.** GT 면적이 초기의 수 %로 남은 잔여 조각이다.
   - 새로운 관측(시야, 배율, 메모리, 전역 탐색, 운동)으로 해결되는 실패가 아니다. 대상이 영상에서 거의 보이지 않는다.
4. **진짜 부재 frame(355)에서의 위험.** 거짓 양성이 몰리는 곳은 다음과 같다.
   - miami-surf: 비슷한 서퍼들
   - drone: 다른 drone
   - longboard
   - smile

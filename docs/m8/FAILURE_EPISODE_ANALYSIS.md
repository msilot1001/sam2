**함의 (실험 전 가설):**
1. 회수 가능한 손실은 크게 두 종류다.
   - 위치형: drone, kite-surf·skate-park의 일부. 대상이 crop 밖에 있다. 전역 탐색과 운동이 필요하다.
   - 표현형: dog-gooses, lady-running. crop 안에서 작아지거나 가려진다. 배율 조절과 prompt가 필요하다.
2. GT 면적이 초기의 수 %인 잔여 조각 frame(약 1/3)은 어떤 생성기로도 J > 0.5 회수가 어렵다. recall 상한을 낮춘다.
3. 진짜 부재 frame(355)이 GT 있음 frame(131)의 2.7배다. rescue의 거짓 양성 비용은 구조적으로 크다.
   - J 계산 규칙상 GT가 빈 frame에서 빈 출력은 J = 1이다. 거기에 무엇이든 출력하면 J = 0이 된다.
   - 그래서 진짜 부재 frame 하나의 거짓 양성은, 회수 하나의 이득(≈ +0.5~0.8)보다 큰 손실(−1)을 낸다.

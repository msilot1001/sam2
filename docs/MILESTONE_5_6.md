# M5.6 — SAM 2.1 실제 영상 실패 종합 감사와 연구 방향 선택

- 브랜치: `exp/m56-comprehensive-failure-audit` (`f277643`에서 분기, 병합하지 않음)
- 모델: 공식 SAM 2.1 Hiera-Tiny, CUDA FP32, 가중치 고정. upstream 파일은 수정하지 않았다.
- 사전 고정: `outputs/milestone56/manifest.json`을 추론 전에 커밋했다(`55b4f53`). PUMaVOS A/B/C 분할, 실패 구간 정의, 분류 규칙, 개입 목록, 회복 판정 기준이 들어 있다.

- 증거 수준 표기:
  - **[관측]** 상관·형태
  - **[통제]** 같은 pre-state에서 한 요인만 바꾼 개입

  - **[배포 가능]** 추론 시 GT 없이 쓸 수 있는 방법

**PUMaVOS 분할** (영상 단위, GT 메타데이터 strata별 hash 순서로 결정):
- **A 탐색:** 9개 영상
- **B 개발:** 6개 영상
- **C 확인:** 9개 영상 / 11개 객체. 확인용으로 남겨 두었으며, 이번에는 **전혀 실행하지 않았다**(테스트로 확인).

**pilot 범위:**
- 영상마다 앞 300 frame만 썼다(사전 고정). 긴 영상의 장기 동작은 다루지 않는다.
- 영상 전체 frame은 CPU에 offload했다. 결과가 동일함을 테스트로 확인했다.

## 2. B0 공식 vs B1 P5

| 세트 | 객체 | B0 J&F | B1 J&F | ΔJ&F [영상 bootstrap CI] | 개선 / 악화 (> 0.01) |
|---|---|---|---|---|---|
| PUMaVOS A | 9 | 0.857 | 0.862 | +0.005 [−0.001, +0.016] | 1 / 0 |
| PUMaVOS B | 6 | 0.912 | 0.912 | +0.0001 [−0.0004, +0.0004] | 0 / 0 |
| **PUMaVOS A+B** | **15** | 0.879 | 0.882 | **+0.003** [−0.0005, +0.0098] | **1 / 0** (billie_shoes +0.048) |
| DAVIS val (M5.5) | 61 | 0.877 | 0.894 | +0.017 [+0.001, +0.040] | 5 / 0 |
| SegTrack (M5.5) | 24 | 0.930 | 0.930 | +0.0002 | 0 / 0 |

- **P5는 독립 영상에서 작다.** 효과는 소수 객체에 몰려 있고, 악화된 객체는 없다.
- 실행 시간과 VRAM은 같다(0.21 s/frame, offload 사용 시 최대 0.98 GB).
- **면적별 J (PUMaVOS, B1):**

| GT 면적 | J |
|---|---|
| < 500 px | 0.28 |
| 500–2k | 0.81 |
| 2k–8k | 0.87 |
| 8k–32k | 0.90 |
| > 32k | 0.97 |

  - DAVIS도 같은 경향이다(< 500 px J 0.18).
  - **작은 객체 결손은 두 독립 데이터에서 반복된다.**
- **GT가 비어 있는 frame에서 예측이 나오는 문제:** 313 frame 중 J 0.77. 대부분 guitar다. 주석은 기타를 뒤에서 보면 '없음'으로 처리하지만 SAM 2는 보이는 기타를 계속 분할한다. 즉 **부분 정의 차이(G)**이고, 모델 오류로 세지 않는다.

## 3. 실패 구간 통계 (J < 0.5, 2 frame 이하 간격은 병합)

| 세트 | 조건 | 구간 | 객체 | 영상 | 실패 frame | 중앙 길이 | 최대 길이 | 미회복 |
|---|---|---|---|---|---|---|---|---|
| PUMaVOS A | B0 / B1 | 13 / 12 | 3 / 3 | 3 / 3 | 252 / 233 | 2 / 5 | 133 / 115 | 1 / 1 |
| PUMaVOS B | B0 / B1 | 3 / 3 | 2 | 2 | 91 / 91 | 1 | 89 | 0 |
| DAVIS val | B0 / B1 | 24 / 27 | 13 | 8 | 291 / 256 | 3 | 79 | 6 / 5 |
| SegTrack | B0 / B1 | 5 / 5 | 4 | 4 | 15 | 4 | 5 | 1 |

- **P5가 없앤 B0 실패 구간:** PUMaVOS 1/16, DAVIS 0/24, SegTrack 0/5. P5는 실패 frame 수를 줄이지만 구간 자체는 거의 없애지 못한다.
- 실패는 **소수 객체에 집중**된다. PUMaVOS는 15개 중 5개, DAVIS는 61개 중 13개다.
- 긴 구간 몇 개가 실패 frame 대부분을 차지한다(billie_shoes 115 frame, guitar 89, paragliding obj3 79). 그래서 frame 수가 아니라 **독립 구간과 영상 수**로 판단했다.

## 4. 실패 분류와 원인 검증 (B1 기준, 객체당 최대 3개 구간, 35개 구간 / 18개 객체 / 13개 영상)

모든 개입은 실패 시작 frame t0의 **같은 B1 상태**에서 출발해 10 frame 동안 진행했다. t0에서 다시 실행한 J가 기록값과 **완전히 같음을 35개 모두 확인**했다(결정론).

**개입 종류:**
- **[통제]** I1: t0 이전의 메모리를 모두 제외한다.
- **[통제]** I2: 직전 6 frame 메모리를 빼고 더 오래된 메모리로 채운다.
- **[사후 GT]** I3: t0에서 GT로 다시 prompt한다.
- **[사후 GT]** 후보 oracle: t0에서 SAM 2의 다중 마스크 후보 3개 중 최고.
- **[사후 GT]** 이미지 oracle: 메모리 없이 GT box로 그 frame만 분할.
- **회복 판정:** 창 평균 J ≥ 0.5이고 대조군 대비 +0.15 이상.

| 관측 분류 (사전 규칙) | 구간 | 객체 / 영상 | 메모리 개입으로 회복 | GT 재prompt로 회복 [사후] | 후보 개선 ≥ 0.15 [사후] | ΔJ I1 / I2 / I3 |
|---|---|---|---|---|---|---|
| E 가림·부재 | **16** | 11 / **9** | 0 | 2 | 0 | −0.15 / −0.03 / +0.07 |
| BC 정지 영상 분할 (작음·얇음) | 8 | 7 / 5 | 0 | 0 | 0 | −0.17 / −0.01 / +0.06 |
| D 메모리 전파 | 7 | 6 / 6 | **2** | 5 | 3 | +0.06 / +0.15 / +0.34 |
| F 정체성·주변 물체 포착 | 2 | 2 / 2 | 0 | 0 | 0 | −0.10 / −0.12 / +0.01 |
| A 출력 해상도 | 1 | 1 / 1 | 0 | 0 | 0 | 0 / 0 / 0 |
| H 미해결 | 1 | 1 / 1 | 0 | 0 | 0 | — |

**메커니즘 시험 결과 (통제 + 사후 GT):**
- **메모리 이력이 원인:** 2개 구간. billie_shoes(신발에서 반바지로 번짐, I2로 0.15 → 0.69), gold-fish obj2.
- **새 대상 정보가 있어야 회복:** 5개 구간. GT 재prompt로만 회복된다(india, kite-surf obj2, lab-coat obj1, paragliding obj2 ×2).
- **GT로 다시 prompt해도 회복되지 않음:** **28개 구간 (14개 객체, 11개 영상)**. 대부분 가림·부재(14)와 작은·얇은 대상의 정지 영상 분할 한계(8)다.

**배포 가능한 메모리 개입:**
- 평균으로는 해롭다. I1 −0.10, I2 +0.005.
- 고치는 경우는 35개 중 2개다. M5-Pre 결론이 독립 데이터에서도 유지된다.

**[사후 GT] 크기 탐침:**
- 작은 객체(중앙 면적 < 1%) 8개를 고정 GT 영역 crop(1.1–2.9배 확대)으로 다시 실행했다.
- 실패 구간 frame의 J는 0.194 → 0.248로 올랐다.
- 객체별로는 4개 개선(kite-surf obj2 +0.20, kite-surf obj1 +0.09, smile +0.09, pimples +0.03), 2개 악화(lab-coat obj1 −0.03, obj2 −0.05), 2개 변화 없음이다.
- 영상 전체로 보면 lab-coat obj1이 −0.39로 크게 나빠졌다.
- **크기는 일부에서만 원인이다. 일관된 원인이라는 근거는 없다.**

**수동 검토 (`figs/`):**
- guitar: 부분 정의 차이(G)
- billie_shoes: 부분·인접 물체로 번짐(D/F)
- pimples: 수 px 크기 대상이며, 마스크가 입으로 번짐(BC + G 성격)

## 5. 지지되는 설명과 지지되지 않는 설명

**지지됨:**
1. 작은 객체 결손은 두 독립 데이터에서 반복되고 효과가 크다. < 500 px에서 J 0.18–0.28이다. [관측]
2. 실패의 대부분(28/35 구간)은 **GT로 다시 prompt해도 10 frame 안에 회복되지 않는다**. 메모리 관리로는 고칠 수 없는 실패다. [사후 GT]
3. 배포 가능한 메모리 개입이 고치는 것은 2/35다. [통제]
4. P5는 독립 데이터에서 +0.003이다. 공학적 교정이며 악화는 없다. [통제]

**지지되지 않음:**
- 메모리 오염이 주된 원인이라는 설명
- 후보 마스크 선택이 문제라는 설명 (3/35)
- 출력 해상도가 주된 원인이라는 설명 (1/35, M5.5의 paragliding 줄 제외)
- 크기 확대가 일관된 해결책이라는 설명 (oracle에서도 결과가 섞임)

**미해결:**
- 가림·부재 16개 구간이 '피할 수 없는 실패'(대상이 거의 보이지 않음)인지, '재획득 실패'인지 분리하지 못했다. 10 frame 창은 짧다.
- B(인코더)와 C(decoder)를 분리하지 못했다(학습 없이는 불가능).

## 7. 후보 3개와 선택 (상세 내용은 `docs/FINAL_RESEARCH_DIRECTION_PROPOSAL.md`)

| 기준 (가중) | C1 작은 대상 확대 추론 | C2 가림 후 재획득 | C3 메모리 오염 방지 |
|---|---|---|---|
| 빈도·독립성 (높음) | 작은 객체 결손이 2개 데이터셋에서 반복. 실패 구간은 BC + A 9개 | 가장 많은 구간(16, 9개 영상) | 2개 구간 |
| 원인 근거 (높음) | 약함–중간: 크기 탐침 4개 개선 / 2개 악화 | 약함: GT 재prompt로도 2/16 | 강함, 그러나 2건 |
| 개선 여지 | 실패 frame J +0.054 [사후], 면적 < 500 px J 0.2–0.3 | 재prompt 상한 +0.07 | +0.15–0.54 (2건) |
| 새로움 | 심사를 거친 SAM2 VOS 방법 없음 | 혼잡 (SAM2Long, SENTRY, DAM4SAM, StreamDAM) | 혼잡 (SAM2Long, SAMURAI, SENTRY) |
| RTX 2080 | 학습 없이 가능 | 가능 | 가능 |
| cherry-pick 위험 | 중간 (작은 객체 수가 적음) | 높음 (주석 정의 혼입, guitar) | 높음 |

**결정:**
- C1 **"작은 대상을 위한 메모리 일관 확대 추론"**을 **잠정 주 방향**으로 고른다.
- 아직 검증되지 않았으므로, 먼저 이를 기각할 수 있는 최소 실험(제안서 §6)을 B 세트에서 수행하고, 통과하면 C 세트에서 한 번 확인한다.

## 8. 다음 milestone 계획 (M6-F, 목표 1–2일)

1. **배포 가능한 최소 확대 추론 구현 (학습 없음):** 직전 예측 마스크의 box로 crop 영역을 정한다. 확대 배율은 prompt 면적으로 한 번 정하고 clip 전체에 고정한다. 신뢰도가 떨어지면(object score < 0) 전체 frame으로 되돌린다. 메모리는 crop 좌표계에서만 유지한다.
2. **평가 대상:** DAVIS val의 작은 객체 13개와 PUMaVOS B 세트. B0 / B1 / B1 + 확대를 비교한다.
3. **사전 고정 기각 기준:** 작은 객체 J&F 개선 < +0.03이거나, 작은 객체의 20% 이상이 −0.01보다 나빠지거나, 큰 객체에서 회귀가 생기면 기각한다.
4. 통과하면 C 세트(11개 객체)에서 한 번만 확인한다. 기각되면 제안서 §7의 대안으로 넘어간다.

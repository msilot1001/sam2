# M7 Stage 3: 표적 조합 실험 (K1–K10)

**사전 규칙:** 조합은 각 구성요소가 서로 다른 독립 실패를 개선한다는 근거가 있을 때만 시도한다. 강한 구성요소보다 나아지지 않으면 복잡도를 버린다.

**사실:**
- Stage 1–2에서 **독립적으로 ADVANCE한 구성요소가 없다.**
- 엄밀히는 조합 단계에 들어갈 근거가 없다.
- 그래도 가장 싼 조합 4개를 같은 재생 기계로 실행해, 상보성이 없다는 것을 직접 확인했다.
- 코드는 `src/spatial/policies.py` (`COMBOS`)에 있고, 결과는 `outputs/milestone7/combos_report.json`이다.

## 3. 결론

- 조합은 회귀를 만들거나(K1, K2: dog-gooses obj5 −0.05), 구성요소와 같은 수준에 머문다.
- 중복된 계산(L-보호 probe, 신원 지도)만 늘린다.
- **조합 방법은 채택하지 않는다.**

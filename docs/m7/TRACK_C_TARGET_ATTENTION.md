# Track C: 목표 조건 특징 결합 (Target-Conditioned Feature Fusion)

**판정: REJECT (현재 학습 데이터 규모에서).**
- 양성 대조는 통과했다. 64개 고정 표본에서 J가 0.869에서 0.965로 올랐다.
- 그러나 5개 head 모두 학습에 쓰지 않은 영상에서 입력보다 나쁘다. DEV 영상 평가에서도 SGGL보다 나쁘다.
- **결론의 범위:** '구조가 학습 불가능하다'가 아니라 'DAVIS train 18개 영상(1,198 frame)으로는 일반화하지 않는다'이다.
- **attention 판단:** attention(T2)은 단순 CNN 결합(T1)보다 덜 나쁠 뿐, 기준선을 넘지 못한다. attention이 필요하다는 근거는 없다.

## 1. 구조 (`src/spatial/feature_fusion.py`, `target_attention.py`)

- **공통 골격:**
  - frozen SAM 2.1 Hiera-T에서 L의 메모리 조건 특징(decoder 입력, 256×64×64)과 L의 logit(256×256)을 받는다.
  - 출력은 L logit에 더하는 잔차다. 마지막 층이 0으로 초기화되어 있어 **초기 출력은 L logit과 정확히 같다**(테스트).
  - 선택은 SGGL과 같다. crop이 채택된 frame에서만 정제한 L을 쓰고, 메모리에는 쓰지 않는다.

| ID | 추가 입력 | 파라미터 |
|---|---|---|
| T0 | 없음 (전이 없는 대조: L만) | 115k |
| T1 | + G의 메모리 조건 특징과 logit. 원본 좌표 → crop 격자로 정확히 재표본화(`sample_global_in_crop`, 정렬 테스트 통과) | 155k |
| T2 | + frame-0 목표 token 4개(fg/bg × L/G, prompt 마스크로 pool한 stride-16 backbone 특징). token이 L과 G 특징을 **따로** cross-attention으로 읽는다(K = 4 token × 4096 / 1024 key, 전체 해상도 all-to-all 없음). 읽은 결과로 FiLM, token 유사도 지도를 채널로 추가 | 355k |
| T3 | + 기권 gate α ∈ [0, 1]: G 쪽 모든 채널에 곱한다. 입력은 G logit 크기, G score, G token 지도 | 355k |
| T4 | + 신원 제약: α × σ(a·(cos_fg_G − cos_bg_G) + b). 목표와 닮지 않은 G 셀은 전이하지 않는다 | 355k |

**기하 정합성 확인:**
- G 특징 격자는 전체 frame을 1024×1024로 비등방 resize한 것이다. crop 격자 셀 중심을 원본 좌표 → G 정규좌표로 옮겨 bilinear 표본화했다(테스트: 셀 중심 오차 < 1e-3 px).
- 실제 영상에서 G logit 재표본화와 L logit의 IoU는 0.55–0.66이다(작은 객체, 해상도 차이 반영).

## 2. 학습 프로토콜 (사전 등록 `preregistration_r2.json`)

- **데이터:** REP(DAVIS 2017 train) crop 객체 43개. 실시간 SGGL 궤적에서 2 frame마다 캐시했다(RTX 2080에서 생성, Vast로 md5 검증 후 전송).
- **분할:** 영상 hash 4:1. fit은 18개 영상 1,198 frame, val은 5개 영상 237 frame이다.
- **최적화:** AdamW lr 1e-3, cosine 감소, weight decay 1e-4, batch 8, 3,000 step, gradient clip 5, seed 0. 모든 변형에 같은 설정이다.
- **손실:** soft target BCE + dice. target은 crop GT를 256 격자로 area resize한 것이다.
- **학습 시간:** 0.8–6.6분. T4는 GPU 상주 데이터 경로라 0.8분이고, 값은 같은 batch다(검증함).
- **최대 VRAM:** 0.2–0.5 GB. GPU 상주 데이터를 쓰면 8 GB다.
- **추론 지연:** head당 frame 14–16 ms (RTX 5090).

## 3. 양성 대조 (fit 64개 고정, 1,500 step, 통과 기준 +0.05)

| head | 입력 J | 학습 후 J | 판정 |
|---|---|---|---|
| T1 | 0.869 | 0.966 | PASS (+0.097) |
| T4 | 0.869 | 0.965 | PASS (+0.096) |

M6.1 head와 달리 loss가 내려가고, 마스크 품질이 실제로 바뀐다. 기울기, 모양, 라벨 정렬이 정상이다.

## 4. 학습 곡선 (val = 학습에 쓰지 않은 영상 5개)

| head | fit J (입력 0.805) | val J 첫 step → 마지막 | val 입력 J | val loss |
|---|---|---|---|---|
| T0 | 0.826 | 0.849 → 0.845 | 0.848 | 0.171 → 0.166 |
| T1 | 0.841 | 0.849 → 0.842 | 0.848 | 0.171 → 0.169 |
| T2 | 0.852 | 0.849 → 0.842 | 0.848 | 0.171 → 0.164 |
| T3 | 0.851 | 0.848 → 0.846 | 0.848 | 0.171 → 0.160 |
| T4 | 0.851 | 0.848 → 0.844 | 0.848 | 0.171 → 0.160 |

**해석:**
- val **loss**는 내려가지만 val **J**는 입력 아래로 떨어진다.
- soft loss가 줄어드는 것이 이진 마스크 개선으로 이어지지 않는다. 경계의 불확실한 픽셀 확률만 조정하는 쪽으로 학습된다.
- "낮은 학습 loss는 VOS 일반화의 증거가 아니다"를 그대로 보여 준다.

## 5. 실제 영상 평가 (DEV, 출력 전용, SGGL 궤적, 작은 객체 16개 / 영상 12개)

| head | Δ vs SGGL | 95% CI | 영상 ↑/↓ | 최악 객체 | 판정 |
|---|---|---|---|---|---|
| T0 | −0.0127 | [−0.028, −0.004] | 0 / 3 | −0.135 | REJECT |
| T1 | −0.0134 | [−0.029, −0.004] | 0 / 2 | −0.125 | REJECT |
| T2 | −0.0013 | [−0.003, +0.001] | 0 / 0 | −0.006 | REJECT |
| T3 | −0.0008 | [−0.003, +0.002] | 0 / 0 | −0.007 | REJECT |
| T4 | −0.0081 | [−0.015, −0.004] | 0 / 1 | −0.048 | REJECT |

**사전 등록한 비교:**

| 비교 | Δ | 95% CI | 의미 |
|---|---|---|---|
| T1 − T0 (전역 특징 전이의 기여) | −0.0007 | [−0.002, +0.002] | **교차 view 특징은 L 단독 정제보다 정보를 더하지 않는다** |
| T2 − T1 (목표 token attention의 기여) | +0.0121 | [+0.003, +0.029] | attention이 CNN보다 **덜 해롭다.** 다만 T2 자체가 SGGL보다 나쁘다 |
| T3 − T2 (기권 경로) | +0.0005 | [−0.001, +0.002] | 차이 없음 |
| T4 − T3 (신원 제약) | −0.0073 | [−0.016, −0.002] | 신원 제약은 오히려 해롭다 |

- **attention 주장 조건:** T2/T3/T4가 T1보다 +0.005 이상, CI > 0이어야 한다. T2와 T3은 이 조건을 만족한다. 그러나 **SGGL보다 낫지 않으므로 attention의 '이득'은 주장할 수 없다.**
- **T2/T3이 덜 나쁜 이유:** 거의 수정하지 않는다(최악 객체 −0.006). FiLM과 token 지도가 잔차를 작게 만드는 쪽으로 학습된 것으로 보인다.

## 6. 남은 가능성과 다음 조건

- **학습 데이터 확대:** 이번 학습 데이터는 18개 영상이다. SA-V(약 50k 영상) 같은 대규모 학습을 하면 결론이 바뀔 수 있다. 다만 그것은 SAM2Refiner / HQ-SAM 2와 같은 '대규모 정제기' 방향이고, 선행연구 위험이 높다.
- **메모리 되쓰기 ablation:** 사전 계획상 결합 마스크를 메모리에 되쓰는 실험은 head가 출력 전용으로 이득을 보인 뒤에만 한다. 그 조건을 충족하지 못해 실행하지 않았다.
